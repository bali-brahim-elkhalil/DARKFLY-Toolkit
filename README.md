🖤 DARKFLY Toolkit

A Cross-Platform Security Toolkit for Kali Linux and Termux

DARKFLY is an independent security toolkit designed to simplify the discovery, management, and installation of security tools in Kali Linux and Termux.

🚀 Features

- INSTALL ALL — Install all compatible available tools.
- LIST AVAILABLE TOOLS — Display available tools.
- INSTALL ONE TOOL — Install a selected tool.
- DOWNLOAD GITHUB SOURCES — Download supported GitHub projects.
- SEARCH TOOLS — Search for available tools.
- SYSTEM DIAGNOSTICS — Check system information and compatibility.

💻 Compatibility

- Kali Linux
- Termux
- Python 3

⚙️ Requirements

- Python 3
- Git
- Internet connection

📥 Installation

Clone the repository:

git clone https://github.com/bali-brahim-elkhalil/DARKFLY-Toolkit.git

Enter the project directory:

cd DARKFLY-Toolkit

Run DARKFLY:

python3 run_darkfly.py

🛡️ Design Principles

- Independent toolkit.
- Cross-platform compatibility.
- Simple interactive interface.
- No Wi-Fi-dependent tools.
- No GPU-dependent tools.
- Batch installation through a single option.
- Skip unavailable or incompatible installers without leaving the program.
